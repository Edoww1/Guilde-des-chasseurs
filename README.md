# ⚔️ Guilde des Chasseurs

## 📖 Description

Guilde des Chasseurs est un projet Java inspiré de *Solo Leveling*. Le joueur incarne un chasseur capable d'affronter des monstres, de gagner de l'expérience et de monter en niveau au fil des missions.

## ✨ Fonctionnalités

- 🗡️ Combats contre différents monstres.
- ❤️ Gestion des points de vie et des dégâts.
- ⭐ Gain d'expérience après chaque victoire.
- 📈 Progression des niveaux et augmentation des dégâts.
- 🎯 Missions comprenant plusieurs monstres.
- 🎁 Récompenses d'expérience à la fin des missions.

## 🛠️ Technologies

- **Langage :** Java
- **JDK :** Java 21

## 🚀 Lancement

1. Cloner le dépôt GitHub.
2. Ouvrir le projet dans IntelliJ IDEA ou un IDE Java.
3. Exécuter la classe `Main`.

## 🎯 Objectif du projet

Mettre en pratique les bases de la programmation orientée objet en Java : classes, objets, encapsulation, collections, boucles et méthodes.
